# Recommendation Service — сервис рекомендаций банка «Стар»

## Название проекта

**Recommendation Service** (`pro.sky:recommendation-service`): сервис персональных рекомендаций банковских продуктов.

## Краткое описание

Банк «Стар» хочет предлагать клиентам продукты, которые им действительно подходят. Сервис анализирует историю транзакций
клиента (типы продуктов, суммы пополнений и трат) и возвращает список рекомендованных продуктов.

Рекомендации строятся по двум видам правил:

* **Статические правила** зашиты в код: «Invest 500», «Top Saving», «Простой кредит» (ТЗ 1).
* **Динамические правила** создаёт менеджер через REST API. Они хранятся в PostgreSQL и собираются из готовых запросов
  `USER_OF`, `ACTIVE_USER_OF`, `TRANSACTION_SUM_COMPARE`, `TRANSACTION_SUM_COMPARE_DEPOSIT_WITHDRAW` (ТЗ 2).

Рекомендации доступны по REST API и через Telegram-бота. Для менеджеров есть статистика срабатываний правил,
для внешних систем — сброс кешей и информация о версии (ТЗ 3).

## Стек технологий

| Область                       | Технология                                                         |
|-------------------------------|--------------------------------------------------------------------|
| Язык                          | Java 17                                                            |
| Фреймворк                     | Spring Boot 3.2 (Web MVC, JDBC, Data JPA)                          |
| Сборка                        | Maven (Maven Wrapper `mvnw`)                                       |
| Основная БД (только чтение)   | H2, файл `transaction.mv.db`, доступ через `JdbcTemplate`          |
| БД правил и статистики        | PostgreSQL 13+, доступ через Spring Data JPA / Hibernate          |
| Миграции                      | Liquibase (formatted SQL)                                          |
| Кеширование                   | Caffeine                                                           |
| Telegram                      | `com.github.pengrad:java-telegram-bot-api`                         |
| Документация API              | springdoc-openapi (OpenAPI 3, Swagger UI)                          |
| Тесты                         | JUnit 5, Mockito, AssertJ, Spring MockMvc                          |
