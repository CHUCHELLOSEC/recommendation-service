# Issues для GitHub Project

Тексты задач для трекера. Создавайте их **по порядку**: номера Issues на GitHub общие с Pull Request
(PR #1 и PR #2 уже существуют), поэтому первая задача получит номер **#3**, последняя **#13**, а PR курсовой
**#14**. Именно эти номера указаны на вики-странице [Traceability](../wiki/Traceability.md). Если порядок нарушится,
поправьте номера в таблице.

Для каждой задачи на доске GitHub Project переводите карточку **Todo → In Progress → Done**,
чтобы в истории задачи были видны перемещения по статусам.

Метки: `ТЗ1`, `ТЗ2`, `ТЗ3`, `курсовая`, `enhancement`, `documentation`.
